# MapMot — мото-карта Ташкента

Карта для езды на мотоцикле по Ташкенту: где запрещено, где удобно ехать, где лежачие полицейские, переезды, камеры и АЗС с бензином.
Одна HTML-страница на Leaflet, данные из OpenStreetMap встроены в файл.

## Структура

```
build/fetch_osm.py     скачивает данные из Overpass в data/raw/*.json (кэш)
build/build_map.py     собирает docs/index.html из data/raw и build/template.html
build/template.html    интерфейс карты (Leaflet, светлая тема, мобильный вид)
data/corridors.json    список рекомендуемых коридоров (правится руками)
data/raw/              сырые ответы Overpass (banned, network, hazards, pois)
docs/index.html        готовая карта, один файл
```

## Пересборка

```bash
python build/fetch_osm.py           # скачать свежие данные (кэш пропускается)
python build/fetch_osm.py --force   # перекачать всё
python build/build_map.py           # собрать docs/index.html
python -m http.server 8765 --directory docs   # открыть http://localhost:8765
```

## Подложка

По умолчанию векторная: стиль Liberty от OpenFreeMap рисуется MapLibre GL прямо на телефоне, поэтому остаётся чётким
на любом зуме и экране. `build_map.py` скачивает стиль и кладёт копию с русскими подписями (`name:ru`, затем латиница)
в `docs/style/liberty-ru.json`. В легенде кнопка «Подложка» переключает на растровые тайлы OSM, если телефон слабый
или WebGL недоступен; выбор запоминается. Векторные тайлы заканчиваются на 14-м зуме, поэтому «Сохранить район»
для них кэширует все уровни приближения сразу.

## Офлайн и установка на телефон

Страница работает как PWA: `docs/sw.js` (service worker) кэширует саму карту со всеми данными, Leaflet из `docs/vendor/`
и просмотренные тайлы OpenStreetMap (до ~6000 штук, старые вытесняются). В легенде кнопка «Сохранить район»
дозагружает текущий вид на три уровня приближения (не больше ~900 тайлов за раз), «Очистить» удаляет кэш тайлов.
Без связи в шапке появляется значок «офлайн»; маршруты без интернета не строятся.

«Весь Ташкент офлайн» в легенде скачивает пакет для векторной подложки: тайлы OpenFreeMap z9–14 по рамке города
(41.18,69.10 – 41.42,69.45), рельеф малых зумов, шрифты подписей и значки стиля. Пакет лежит в отдельном кэше
`mapmot-pack-v1`, не вытесняется и переживает обновления приложения. Векторные тайлы хранятся без номера недельной
сборки OpenFreeMap в пути, поэтому пакет продолжает работать после её смены. Страница просит `navigator.storage.persist()`,
чтобы браузер не чистил пакет при нехватке места; повторное нажатие докачивает пропущенное или обновляет пакет целиком.
TileJSON service worker берёт сначала из сети, чтобы онлайн всегда была актуальная сборка тайлов.
Для растровой подложки пакета нет: правила сервера тайлов OSM запрещают массовое скачивание.

Установка: Android Chrome предложит «Установить приложение» (или меню ⋮ → «Добавить на главный экран»),
iPhone Safari: «Поделиться» → «На экран Домой». Иконка и манифест лежат в `build/static/`.

Версия кэша считается из содержимого сборки, поэтому после `build_map.py` и пуша телефон при следующем открытии
с интернетом сам подтянет новую версию и покажет уведомление «обновите страницу».
GitHub Pages отдаёт файлы с `Cache-Control: max-age=600`, поэтому `sw.js` запрашивает страницу с перепроверкой
на сервере (`cache: 'no-cache'`), а файлы новой версии при установке берёт мимо кэша браузера (`cache: 'reload'`).
Без этого после пуша телефон до 10 минут показывал бы прошлую версию.
Страница регистрирует `sw.js?v=<версия сборки>`, так что новая версия service worker ставится при первом же открытии,
а плашка «Есть новая версия» появляется, только если открытая страница старее установившегося service worker.

## Автообновление

Workflow `.github/workflows/update-map.yml` каждый понедельник скачивает свежие данные OSM, пересобирает `docs/index.html`
и коммитит его, если что-то изменилось. GitHub Pages подхватывает коммит автоматически.
Запустить вручную: вкладка Actions на GitHub, «Update map data», «Run workflow», либо `gh workflow run update-map.yml`.

## Слои

| Слой | Источник | По умолчанию |
|------|----------|--------------|
| Запрет (красный) | ways с `motorcycle=no/private`, `motorcycle:conditional`, `motor_vehicle=no`, `access=no` на крупных дорогах | вкл |
| Коридоры (зелёный) | `data/corridors.json`, подбор по названию улицы в сети trunk…tertiary | вкл |
| Опасности (оранжевый) | `traffic_calming`, `railway=level_crossing`, `hazard`, плохое `surface`/`smoothness` | выкл |
| Радары (фиолетовый) | `highway=speed_camera` и relation `type=enforcement` (скорость, светофор); в карточке лимит и направление | выкл |
| АЗС / сервис (синий) | `amenity=fuel` без чисто газовых, `shop=motorcycle`, шиномонтаж, мотопарковки | выкл |

| Отметки (фиолетовый) | `data/marks.json` (общие) + свои отметки в браузере | вкл |

Точки опасностей и сервиса рисуются начиная с 14-го зума. Выбор слоёв запоминается в браузере.

## Свои отметки

Долгое нажатие на карту (или кнопка «＋», затем прицел и ещё раз «＋») открывает форму: тип отметки и комментарий.
Типы: знак запрета, опасное место, пост/патруль, хорошая дорога, АЗС/сервис, заметка.
Свои отметки хранятся в браузере телефона и рисуются с пунктирной рамкой; их можно изменить или удалить из карточки.

Чтобы отметки попали в общую карту: легенда «❔», «Экспорт отметок» (откроется «Поделиться» или JSON скопируется в буфер),
затем вставить объекты в `data/marks.json` и пересобрать. Формат:

```json
{"id": "m1", "type": "sign", "lat": 41.3111, "lon": 69.2797, "text": "описание", "date": "2026-09-14", "url": "необязательно"}
```

«Импорт» в легенде принимает такой же JSON и добавляет отметки в браузер.

## Отметки о знаках

Нажмите на красную улицу: в карточке кнопки «⛔ Знак есть» и «🟢 Знака нет». Отметка ставится в месте нажатия
(лучше нажимать у въезда, где висит знак) и действует на непрерывный участок улицы: сегменты с тем же названием,
соединённые концами, обычно отдельно для каждого направления. Участки считает `build_map.py` (свойство `run`),
в карточке участок подсвечен ярко-жёлтым. Повторное нажатие активной кнопки снимает отметку.

- «Знак есть» делает участок сплошным красным, «Знака нет» рисует его серым пунктиром. Действует последняя по времени отметка.
- Улица без запрета в OSM: долгое нажатие на карте, тип «Знак запрета мото». Название улицы берётся у ближайшего
  красного участка или через Nominatim (в запрос уходят координаты точки), отрезок улицы подгружается из Overpass
  и рисуется красными точками. Без связи отметка сохраняется по координатам, улица подставится позже.
- Маршрут объезжает каждую отметку «знак есть» (зона около 50 м). «Знака нет» маршрут не меняет: Valhalla берёт
  запреты из OSM. Поэтому в карточке есть ссылка «Заметка в OSM», текст заметки копируется в буфер обмена.
- Отметки хранятся в браузере вместе с остальными и попадают в экспорт/импорт. Общие лежат в `data/marks.json`
  с полями `type` (`sign` или `nosign`), `lat`, `lon`, `date` и необязательными `way`, `street`.

## Маршрут в обход запретов

Кнопка «🧭», затем два нажатия на карту (или «я здесь» для старта). Маршрут считает публичный сервер Valhalla
(valhalla1.openstreetmap.de) в режиме `motorcycle`, который учитывает тег `motorcycle=no` из OSM.
Вокруг отметок типа «знак запрета» (общих и своих) добавляются зоны исключения ~50 м, чтобы объезжать и то, чего нет в OSM.
После построения показываются километраж, время и проверка: не идёт ли маршрут вдоль красного участка.
Кнопки «Google Maps» и «Яндекс» открывают навигатор с промежуточными точками вдоль этого же пути.

## Режим поездки

После построения маршрута кнопка «▶ Поехали по карте» включает ведение прямо в приложении. Чужие навигаторы
при съезде с пути перестраивают маршрут через запретные улицы, здесь объезд сохраняется.

- Сверху стрелка следующего манёвра, расстояние до него и текст подсказки; снизу остаток пути, время и час прибытия.
- Голос на русском через синтез речи телефона: заранее («Через 300 метров поверните направо…», 200–500 м в зависимости
  от скорости), у самого поворота и «Продолжайте движение» на прямых длиннее километра. Кнопка 🔊/🔇 выключает голос.
- Отъезд от маршрута дальше 40 м три отметки GPS подряд перестраивает маршрут от текущей точки с учётом направления
  движения (`heading` в запросе Valhalla), снова в обход запретов и отметок «знак есть». Не чаще раза в 12 секунд.
- Экран не гаснет (Screen Wake Lock), карта едет за мотоциклом. Если сдвинуть карту, появится «◎ За мной»; «Обзор» показывает весь маршрут.
- «Стоп» срабатывает со второго нажатия. У точки назначения поездка завершается сама.
- Valhalla называет улицы по тегу `name` (латиница). Сборка пишет `docs/ru-names.json` (name → name:ru для всех улиц
  города, запрос `names` в `fetch_osm.py`); файл загружается при построении маршрута и хранится в кэше service worker,
  поэтому подсказки звучат по-русски. Склейку фраз Valhalla («…улица., затем Поверните») карта исправляет сама.

Ограничения веб-приложения: GPS работает, только пока карта открыта на экране; для построения и перестроения маршрута нужен интернет.

## Достоверность запретов

`build/fetch_ban_history.py` по истории OSM находит правку, которая поставила запрет на каждый сегмент, и сохраняет
автора, дату и комментарий в `data/ban_sources.json`. В карточке красного участка это показано как:

- ✅ по дорожным знакам: комментарий правки упоминает знаки или мотоциклиста (например, frozenspider 2025-2026);
- ⚠️ массовая правка: тег добавлен пакетной правкой `#wbgeo` в мае 2026 по панорамам, стоит проверить на месте;
- ⏳ старые данные: тег стоит с 2010-2019 годов;
- 🚫 дорога закрыта для всех (`access=no`), например Президентская трасса;
- ℹ️ обычная правка OSM без пояснений.

Показ красных улиц: подтверждённые по знакам и закрытые дороги рисуются сплошной линией, массовая правка длинным
пунктиром, старые данные коротким. От 15-го зума показаны точки въезда в зону запрета (⛔, конец красного участка,
за которым запрета нет) и подписи улиц. Нажатие подсвечивает всю улицу жёлтым, кнопка «Показать всю улицу»
подгоняет карту. В легенде «Список запретов» открывает перечень улиц с числом сегментов.

## Ограничения

Карта основана на данных OSM и не заменяет знаки. Часть запретов в OSM может быть устаревшей или неполной.
