# MapMot — мото-карта Ташкента

Карта для езды на мотоцикле по Ташкенту: где запрещено, где удобно ехать, где лежачие полицейские, переезды, камеры и АЗС с бензином.
Одна HTML-страница на Leaflet, данные из OpenStreetMap встроены в файл.

## Структура

```
build/fetch_osm.py     скачивает данные из Overpass в data/raw/*.json (кэш)
build/build_map.py     собирает docs/index.html из data/raw и build/template.html
build/template.html    интерфейс карты (Leaflet, светлая тема, мобильный вид)
data/corridors.json    список рекомендуемых коридоров (правится руками)
data/raw/              сырые ответы Overpass (banned, network, hazards, pois)
docs/index.html        готовая карта, один файл
```

## Пересборка

```bash
python build/fetch_osm.py           # скачать свежие данные (кэш пропускается)
python build/fetch_osm.py --force   # перекачать всё
python build/build_map.py           # собрать docs/index.html
python -m http.server 8765 --directory docs   # открыть http://localhost:8765
```

## Офлайн и установка на телефон

Страница работает как PWA: `docs/sw.js` (service worker) кэширует саму карту со всеми данными, Leaflet из `docs/vendor/`
и просмотренные тайлы OpenStreetMap (до ~6000 штук, старые вытесняются). В легенде кнопка «Сохранить район»
дозагружает текущий вид на три уровня приближения (не больше ~900 тайлов за раз), «Очистить» удаляет кэш тайлов.
Без связи в шапке появляется значок «офлайн»; маршруты без интернета не строятся.

Установка: Android Chrome предложит «Установить приложение» (или меню ⋮ → «Добавить на главный экран»),
iPhone Safari: «Поделиться» → «На экран Домой». Иконка и манифест лежат в `build/static/`.

Версия кэша считается из содержимого сборки, поэтому после `build_map.py` и пуша телефон при следующем открытии
с интернетом сам подтянет новую версию и покажет уведомление «обновите страницу».

## Автообновление

Workflow `.github/workflows/update-map.yml` каждый понедельник скачивает свежие данные OSM, пересобирает `docs/index.html`
и коммитит его, если что-то изменилось. GitHub Pages подхватывает коммит автоматически.
Запустить вручную: вкладка Actions на GitHub, «Update map data», «Run workflow», либо `gh workflow run update-map.yml`.

## Слои

| Слой | Источник | По умолчанию |
|------|----------|--------------|
| Запрет (красный) | ways с `motorcycle=no/private`, `motorcycle:conditional`, `motor_vehicle=no`, `access=no` на крупных дорогах | вкл |
| Коридоры (зелёный) | `data/corridors.json`, подбор по названию улицы в сети trunk…tertiary | вкл |
| Опасности (оранжевый) | `traffic_calming`, `railway=level_crossing`, `highway=speed_camera`, `hazard`, плохое `surface`/`smoothness` | выкл |
| АЗС / сервис (синий) | `amenity=fuel` без чисто газовых, `shop=motorcycle`, шиномонтаж, мотопарковки | выкл |

| Отметки (фиолетовый) | `data/marks.json` (общие) + свои отметки в браузере | вкл |

Точки опасностей и сервиса рисуются начиная с 14-го зума. Выбор слоёв запоминается в браузере.

## Свои отметки

Долгое нажатие на карту (или кнопка «＋», затем прицел и ещё раз «＋») открывает форму: тип отметки и комментарий.
Типы: знак запрета, опасное место, пост/патруль, хорошая дорога, АЗС/сервис, заметка.
Свои отметки хранятся в браузере телефона и рисуются с пунктирной рамкой; их можно изменить или удалить из карточки.

Чтобы отметки попали в общую карту: легенда «❔», «Экспорт отметок» (откроется «Поделиться» или JSON скопируется в буфер),
затем вставить объекты в `data/marks.json` и пересобрать. Формат:

```json
{"id": "m1", "type": "sign", "lat": 41.32554, "lon": 69.32392, "text": "описание", "date": "2026-09-09", "url": "необязательно"}
```

«Импорт» в легенде принимает такой же JSON и добавляет отметки в браузер.

## Маршрут в обход запретов

Кнопка «🧭», затем два нажатия на карту (или «я здесь» для старта). Маршрут считает публичный сервер Valhalla
(valhalla1.openstreetmap.de) в режиме `motorcycle`, который учитывает тег `motorcycle=no` из OSM.
Вокруг отметок типа «знак запрета» (общих и своих) добавляются зоны исключения ~50 м, чтобы объезжать и то, чего нет в OSM.
После построения показываются километраж, время и проверка: не идёт ли маршрут вдоль красного участка.
Кнопки «Google Maps» и «Яндекс» открывают навигатор с промежуточными точками вдоль этого же пути.

## Ограничения

Карта основана на данных OSM и не заменяет знаки. Часть запретов в OSM может быть устаревшей или неполной.
