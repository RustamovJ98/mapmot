# MapMot — мото-карта Ташкента

Личная карта владельца для езды на мотоцикле по Ташкенту — с телефона, на ходу,
на светлом фоне. Устройство, слои, сборка и проверки данных — в `README.md`;
здесь — то, чего там нет.

Репозиторий открытый (`RustamovJ98/mapmot`, сайт —
https://rustamovj98.github.io/mapmot/), поэтому в git ничего личного.

## Порядок работы

- Claude правит и коммитит, push владелец делает сам в своём терминале.
- Перед новыми коммитами — `git pull --ff-only`: по понедельникам бот
  обновления данных коммитит в `origin/main`.
- Перед локальной сборкой, которая уйдёт в push, —
  `python build/fetch_osm.py --force`: сборка из старых `data/raw` однажды
  откатила на сайте свежие данные бота.
- Теги OSM перед действием сверять на `api.openstreetmap.org`: зеркало
  `overpass.kumi.systems` отстаёт на дни.
- Предупреждений о запретах при приближении в режиме поездки владелец
  не хочет — без его просьбы не добавлять.

## Проверка

- Интерфейс проверять по содержимому DOM, а не по уменьшенному снимку экрана:
  повтор имени функции однажды превратил значки в текст, а на снимке этого
  не было видно.
- В панели браузера WebGL рисует медленно: первый снимок после загрузки
  пустой, нужно подождать несколько секунд.
- Версию сборки владелец читает в легенде — так он проверяет, что телефон
  получил новую.
- Локальный `http.server` не повторяет кэш GitHub Pages (`max-age=600`):
  ошибку обновления ловить на копии `docs`, отданной с этим заголовком
  на другом порту.
- Режим поездки без GPS: подменить `navigator.geolocation.watchPosition`
  и кормить его точками `ride.route.pts`; `speechSynthesis.speak` подменить
  и писать текст подсказок в журнал.
- `build/merge_reports.py` проверять локально с переменными `ISSUE_BODY`,
  `MARKS_FILE`, `DOCS_MARKS_FILE`, `GITHUB_OUTPUT`; поток «Знаки в общую
  карту» — подменой `window.open` и `fetch('marks.json')`.

## Подводные камни

- Zoom Leaflet = zoom MapLibre − 1. MapLibre — 5.24 UMD: шестая версия
  выходит только как ESM.
- OpenFreeMap отвечает 403 на User-Agent Python `urllib` по умолчанию —
  задавать свой. На неизвестную версию сборки он отвечает 200, поэтому
  попадание в офлайн-пакет доказывать маркером в кэше под ключом пакета.
- Значки PNG рисует Edge без окна, каждый раз с новым `--user-data-dir`.
